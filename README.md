# Motorized-ND-Filter----UCSD-Internship
Two neutral density filters that are remotely moved using an NI-DAQ, NEMA 17 stepper motors, and an Arduino NANO.

Motors can be driven with A4988 and DRV8825 drivers.

The aim of this instrument is to gather data on the quantum yield from MoS2 (Molybdenum disulfide) at different voltages and intensities of light.
